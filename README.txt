TRISH'S GRADUATION APPRECIATION WEBSITE
=======================================

FILES
- index.html  : page content
- style.css   : design and responsive layout
- script.js   : buttons, animations and confetti
- images/     : add your own photographs here

PHOTOS
The website currently uses:
- images/trish-1.jpg
- images/trish-2.jpg
To replace a photo, add the replacement image to the images folder with the
same filename. JPG and PNG formats are supported.

RUN ON YOUR LAPTOP
1. Extract the ZIP file.
2. Open the trish_graduation_surprise folder in Visual Studio Code.
3. Install the "Live Server" extension if you do not already have it.
4. Right-click index.html and choose "Open with Live Server".
   You can also double-click index.html to open it in a browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create or sign in to a GitHub account at https://github.com
2. Click the + menu, choose "New repository".
3. Name it: trish-graduation-surprise
4. Choose Public, then create the repository.
5. Upload index.html, style.css, script.js and the images folder.
   Keep the folder structure exactly as it is.
6. Open the repository's Settings > Pages.
7. Under "Build and deployment", choose "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then Save.
9. Wait a few minutes. GitHub will show your website address in Settings > Pages.
10. Open that address on your phone to test it, then share the link with Trish.

PERSONALISE BEFORE SHARING
- Replace the general friendship sentences with details that are true to your friendship.
- Add the photos you have.
- Check the graduation year and all text before publishing.
- Ask permission before using any photo she may not want shared publicly.
- A public GitHub Pages link can be viewed by anyone who has the link (and may be discoverable).
  Do not include private information or photos she would not want online.

TIP
You can make a QR code from the published website URL and print it on a small card.
Write: "Scan this — I made something for you. Congratulations, Trish! ♡"
